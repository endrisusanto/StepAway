Sinkronisasi Smartband BLE

Stream Key & QR Pairing

Isolasi data antar streamer dengan Stream Key pribadi. Sambungkan aplikasi Android cukup dengan scan QR code.

3 Langkah Cepat Mulai Streaming

Siap digunakan dalam kurang dari 2 menit tanpa instalasi server rumit.

01

Daftar / Login Akun

Masuk dengan Google atau buat akun creator untuk memperoleh Stream Key unik Anda.

02

Scan QR di HP Android

Buka aplikasi StepAway di smartphone Anda dan scan QR code untuk menghubungkan sensor.

03

Pasang di OBS Studio

Salin link Browser Source ke OBS Studio. Widget telemetri real-time siap disiarkan langsung ke penonton.
