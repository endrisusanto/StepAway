Panduan Aplikasi Android APK

  1. Unduh dan install aplikasi StepAway APK di smartphone Android Anda.
  2. Buka aplikasi, masukkan Server URL: https://stepaway.endrisusanto.my.id
  3. Masukkan User ID: streamer
  4. Klik tombol Start Tracking. Sensor langkah HP dan Smartband BLE (0x180D) akan otomatis terhubung dan mengirim data real-time ke OBS.

Program Hotkey OBS & Stream Deck

Hubungkan tombol keyboard, Stream Deck, Touch Portal, atau OBS Advanced Scene Switcher untuk mengubah skor secara instan saat siaran.

Kirim HTTP GET / POST ke URL ini untuk otomatis mengubah skor tanpa membuka tab dashboard.

+1 WIN /api/users/:user/score/action?action=win&key=...
+1 LOSE /api/users/:user/score/action?action=lose&key=...
-1 WIN /api/users/:user/score/action?action=win_dec&key=...
-1 LOSE /api/users/:user/score/action?action=lose_dec&key=...
RESET /api/users/:user/score/action?action=reset&key=...
Alt + W Tambah Win (+1)
Alt + L Tambah Lose (+1)
Alt + Shift + W Kurangi Win (-1)
Alt + Shift + L Kurangi Lose (-1)
Alt + R Reset Skor (0 - 0)
