Panduan Integrasi Android APK

  1. Install aplikasi StepAway Android di smartphone Anda.
  2. Buka aplikasi, masukkan Server URL: https://stepaway.endrisusanto.my.id
  3. Masukkan User ID: streamer
  4. Klik tombol Start Tracking. Sensor langkah HP dan Smartband BLE (0x180D) akan otomatis terhubung dan mengirim data real-time ke OBS.
